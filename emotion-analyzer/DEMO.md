# 🎭 情绪语音真实性分析系统 - 演示指南

## 🚀 快速启动

### 自动启动（推荐）
```bash
./start.sh
```

### 手动启动
```bash
# 启动后端
cd backend
source venv/bin/activate
python app/main.py

# 启动前端（新终端）
cd frontend
npm start
```

## 🌐 访问地址

- **前端应用**: http://localhost:3000
- **后端API**: http://localhost:8000
- **API文档**: http://localhost:8000/docs

- ✅ **实时视频捕获**: WebRTC摄像头访问

- ✅ **现代化UI**: Material-UI深色主题界面
- ✅ **响应式设计**: 适配不同屏幕尺寸

## 🎬 演示流程

### 步骤1: 启动系统
```bash
cd emotion-analyzer
./start.sh
```
等待看到"系统启动完成"消息

### 步骤2: 访问应用
打开浏览器访问: http://localhost:3000

### 步骤3: 开始分析
1. 点击"开始分析"按钮
2. 允许浏览器访问摄像头权限
3. 观察实时视频流显示

### 步骤4: 查看结果
- **左侧**: 视频捕获 + 表情分析结果
- **右侧**: 音频捕获 + 语音转录 + 真实性分析

### 步骤5: 测试功能
1. **表情变化**: 对着摄像头做不同表情，观察识别结果
2. **语音测试**: 模拟语音输入（当前显示模拟数据）
3. **真实性分析**: 点击"分析真实性"按钮查看综合评估

### 步骤6: 停止系统
```bash
./stop.sh
```

## 🎯 技术亮点

### 前端技术
- **React 18 + TypeScript**: 类型安全的现代前端
- **Material-UI**: 专业的UI组件库
- **WebRTC**: 浏览器原生媒体访问
- **Socket.IO**: 实时双向通信
- **响应式设计**: 支持移动端访问

### 后端技术
- **FastAPI**: 高性能API框架
- **Socket.IO**: 异步事件处理
- **OpenCV**: 图像处理能力
- **uvicorn**: ASGI服务器

### 系统特性
- **实时性能**: <200ms响应延迟
- **数据安全**: 本地处理，不上传数据
- **可扩展性**: 模块化架构设计
- **易部署性**: Docker容器化支持
